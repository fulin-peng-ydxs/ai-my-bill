# 公网部署演进方案

## 当前结论

公网部署目前**不可执行、未验证**。仓库只保留 `public-direct` 与 `public-behind-edge` 两个能力契约，`IMPLEMENTED=0`，环境向导和初始化入口会明确拒绝；不能把内网IP、内部CA或 `0.0.0.0/0` 来源配置直接暴露到互联网。

这份文档定义后续实现必须满足的抽象边界和落地清单，不登记任何尚不存在的域名、云主机或供应商。真实域名、主机、DNS记录、边缘服务、证书、端口、密钥托管和验收结果仍只进入 `.local/web/deploy-targets/<目标>.env` 与 `agent-works/deployment/cases/<环境>/README.md`。

## 两种部署模式

| 模式 | 公网入口 | TLS责任 | 源站暴露 | 适用前提 |
|---|---|---|---|---|
| `public-direct` | 域名直接解析到业务主机/公网负载均衡 | 源站ACME或组织证书自动化 | 主机80/443可达 | 有稳定公网地址、DNS自动化、主机网络防护和外部告警 |
| `public-behind-edge` | CDN/WAF/云负载均衡接收用户流量 | 边缘证书 + 边缘到源站TLS | 只允许可信边缘访问 | 已选定边缘供应商、可信代理网段、源站认证及真实IP规则 |

两种模式共享应用、数据库、迁移、候选构建、目标解析、备份和运维入口；它们必须使用各自独立的Compose/Caddy覆盖、预检和验收，不能在通用脚本中散落具体云厂商判断。

## 通用安全与运维门禁

公网profile变为可执行前至少完成：

1. 域名所有权、DNS变更责任、IPv4/IPv6策略和回退TTL；健康地址使用域名，不再用内部IP证书。
2. 只开放所需入口。数据库、应用、Caddy管理端和调试端不发布；安全组/防火墙由实例外部制度管理并在案例记录。
3. 公共信任TLS自动签发与续期、证书状态持久化、到期外部告警和失败回退；不向公网客户端分发内部CA。
4. 管理入口策略：优先VPN/零信任访问；若必须公网开放，增加独立强认证、来源限制、审计和暴力破解防护。普通ADMIN角色本身不等于网络边界。
5. 真实客户端IP只接受已认证可信代理写入的头。直连时删除外部伪造转发头；边缘模式按供应商CIDR限制源站并验证边缘到源站身份。
6. 登录/CSRF/Cookie/CORS/CSP/RLS维持现有同源安全，不因公网化放宽。按互联网威胁模型重新做速率限制、依赖/镜像/宿主扫描和渗透验证。
7. 异机加密副本、独立密钥托管、外部监控告警、日志保留和恢复演练全部落地；同机journald和工作站 `.local` 副本不足以支撑公网承诺。
8. 明确RPO/RTO、维护窗口、流量切换/回退、schema兼容和数据驻留要求；不存在无条件数据库自动回滚。

## 分层实现清单

| 层次 | 必须新增或改变 | 不应包含 |
|---|---|---|
| profile | 将对应 `IMPLEMENTED` 置1，登记入口类型、TLS、覆盖文件和必需能力 | 域名、IP、账号或供应商secret |
| 目标契约 | 域名、外部健康地址、可信代理/源站认证引用、外部备份与告警引用 | 密码、令牌、私钥正文 |
| Compose/Caddy覆盖 | 80/443、ACME状态卷或源站TLS、可信代理、最小网络 | 内网CA路径和实例硬编码 |
| 宿主预检 | DNS解析、端口归属、时间同步、证书/边缘可达、源站未越界暴露 | 自动修改未知防火墙或DNS |
| 初始化/更新 | 复用候选、迁移和状态机，按profile选择入口实现 | 用内网覆盖冒充公网覆盖 |
| 运维/恢复 | 域名HTTPS检查、外部告警、异机归档与密钥、入口切换演练 | 自动覆盖生产数据 |
| 案例 | 实际资源、证书、摘要、扫描、客户端和恢复证据 | 未执行计划或秘密正文 |

实现顺序应是：确认模式和供应商责任 → 完成威胁/网络设计 → 新增覆盖与字段 → 只读预检 → 隔离环境初始化 → 安全/恢复/告警验证 → 真实案例验收 → 最后把profile设为可执行。仅修改 `IMPLEMENTED=1` 不构成实现，配置测试必须拒绝缺少任一能力的profile。

## 从内网迁移的边界

公网环境默认视为新环境，不直接原地把现有内网案例开放端口。需要迁移数据时，先按异机备份和恢复流程在隔离公网候选环境恢复，重签公共域名证书，验证租户/权限/导出/注销重放和外部告警，再安排维护窗口与DNS/边缘切换。旧内部CA、CentOS7例外、全来源内网授权、当前主机风险接受和历史镜像批准均不自动继承。

正式上线前至少保留一次从异机归档与独立托管密钥开始的完整恢复证据，以及一次证书续期和入口回退演练。没有这些证据时，公网模式仍标记未实现。
