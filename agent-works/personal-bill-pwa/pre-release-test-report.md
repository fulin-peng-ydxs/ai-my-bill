## 4. Playwright 关键链路

- 普通用户使用真实 Cookie/CSRF 会话登录，进入“记一笔”，打开“收支明细”并看到固定 UUID 样本“发布候选咖啡”，打开“收支报表”看到 `18.50`，直访 `/admin` 保持目标 URL并显示“无权访问此页面”。
- 管理员登录进入“用户管理”，直访普通用户 `/entry` 被前端守卫重定向回 `/admin`。
- fixture 仅存在于 `server/src/test`；初始化器在 Spring/Flyway 产生写入前同时校验 `test` profile、`MY_BILL_E2E_WRITE=1`、显式 JDBC URL及实时数据库指纹。数据库由 `mktemp` 创建，脚本退出时先停止前后端进程，再停止并删除该临时 PostgreSQL 集群。
